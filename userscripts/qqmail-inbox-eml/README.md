# QQ 邮箱收件箱 EML 下载按钮

安装文件：[qqmail-inbox-eml.user.js](./qqmail-inbox-eml.user.js)。

## 安装

1. 打开 Chrome 的“扩展程序 → 管理扩展程序 → 篡改猴 → 详情”，开启“允许运行用户脚本”。当前 Chrome 中仅开启“开发者模式”还不够；这个独立开关必须开启，油猴才能运行已导入脚本。
2. 在 Chrome 的 Tampermonkey（篡改猴）扩展中选择“添加新脚本”。
3. 删除编辑器中的默认内容，粘贴 `qqmail-inbox-eml.user.js` 的完整内容并保存。
4. 刷新已经登录的 QQ 邮箱，进入收件箱，每封邮件右侧会出现“下载 EML”按钮。

脚本适配当前检查到的新版 QQ 邮箱：`https://wx.mail.qq.com/home/…#/list/1`。不支持旧版 `/cgi-bin/` 邮箱页面。按钮仅出现在收件箱，滚动加载、切换页面后会自动补齐。

## 下载行为

- 点击按钮通过当前登录会话调用 QQ 邮箱官方 EML 导出入口，文件交由 Chrome 下载。
- 导出原始邮件，保留邮件头、正文、MIME 内容及邮件内的普通附件；中转站或超大附件链接是否仍可下载取决于 QQ 邮箱及链接有效期。
- 点击按钮不会触发邮件行的打开或勾选操作。脚本本身不调用标记已读、删除或发送邮件接口。
- 不需要邮箱密码、IMAP 授权码或额外脚本权限；不将邮件发往第三方，也不保存登录会话。
- 下载采用与官方入口一致的新窗口方式。Chrome 通常直接接收下载；会话失效等服务器提示可能显示在新标签页中。脚本不把“已发起请求”显示为“下载成功”。

如果没有按钮，先点击油猴图标检查提示。如果显示“请启用‘允许用户脚本’扩展设置”，请完成上述第 1 步，再刷新邮箱；已安装脚本的启用状态不能替代这一开关。再确认扩展和脚本已启用、正在使用上述新版地址。如果出现“请刷新重试”，请刷新邮箱或重新登录。如果 Chrome 提示阻止了弹出窗口，请允许 QQ 邮箱的该次下载操作。
